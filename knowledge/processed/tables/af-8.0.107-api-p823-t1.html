上下文标题路径：5 网络 / 5.2 接口 / 5.2.20 从rstpd批量获取接口信息

data.items.statestring端口rstp状态
枚举值:[
DISABLED:未开启的端口
DISCARDING:不转发用户流量, 不学习MAC地址
LEARNING:不转发用户流量, 学习MAC地址
FORWARDING:转发用户流量, 学习MAC地址
NOSTP:不是stp端口
UNKNOW:未知端口
]
data.items.rolestring端口rstp角色
枚举值:[
ROOT:根端口, 去往根桥路径最短的端口
DESIGNATE:指定端口,
向下游交换设备转发BPDU报文的端口
ALTERNATE:根端口的备份端口
BACKUP:指定端口的备份端口
NONSTP:不参与rstp端口
UNKNOW:未知端口
]
data.items.rootBridgestring设备的根桥
data.items.rootPathCostuint32根路径开销
data.items.designBridgestring设备的指定桥
data.items.designPortstring指定端口id
data.items.rstpBpduRxuint64收到rstp报文数量
data.items.configBpduRxuint64收到config报文数量
data.items.tcnBpduRxuint64收到tcn报文数量
data.items.bpduTxuint8计数器，发送bodu时递增，每秒递减一次，如果值达
到TxHoldCount，则传输会延迟
