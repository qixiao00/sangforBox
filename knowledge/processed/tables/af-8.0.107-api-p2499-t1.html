_startint32否起始位置，从 0 开始
最小值:0
最大值:2000000
actionuint32否过滤动作
枚举值:[
1:动作允许
0:动作拒绝
]
_lengthint32否获取最大长度，限制最大值，如果数据不够
可能返回小于 length
最小值:1
最大值:200
默认值:100
dstPortuint16否匹配目的端口
最小值:0
最大值:65535
namestring否资源名
最大长度:1440
iduint32否过滤id，保留字段
uuidstring否资源全局唯一ID
最大长度:32
_orderstring否指定排序方式（正序/倒序）
默认值:asc
枚举值:[
asc:按升序排列
desc:按降序排列
]
srcPortuint16否匹配源端口
最小值:0
最大值:65535
_selectstring否选择字段，字段用逗号分隔
最大长度:1000
protoNumuint8否匹配协议
最小值:0
最大值:255
actionTimestring否匹配时间
dstIpstring否匹配目的ip地址
格式:ip-address
_searchstring否模糊搜索关键字
最大长度:95
invalidStatusbool否过滤失效状态策略
_sortbystring否指定排序字段
最大长度:100
policyGroupstring否过滤策略组
最小长度:1
最大长度:95
enablebool否过滤启禁用
