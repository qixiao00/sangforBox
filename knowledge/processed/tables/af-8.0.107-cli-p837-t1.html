名称范围输入格式说明
contact-STRING设置snmp服务的sysContact信息
name <name-value>-STRING主机名
ip <ip-address>-A.B.C.D 地址格式
A.B.C.D
A:B:C:D::E 地址格式
A:B:C:D::E		主机ip地址
community <community-name>length:(1-95)STRING主机团体名
privilege <privilege-type>枚举值:[
ro: 只读权限
rw: 读写权限
]		ENUM可读可写权限设置
net <net-value>-A.B.C.D/M 地址格式:
A.B.C.D/M
A.B.C.D/E.F.G.H
地址格式:
A.B.C.D/E.F.G.H
A:B:C:D::E/M
地址格式:
A:B:C:D::E/M
A:B:C:D::E/F:G:H:I::J
Address format:
A:B:C:D::E/F:G:H:I::J		子网地址
location-STRING设置snmp服务的sysLocation信息
dest_ip-A.B.C.D 地址格式:
A.B.C.D
A:B:C:D::E Address
format: A:B:C:D::E		trap主机ip地址
enc-protocol <enc-protocol-type>枚举值:[
des: DES
aes: AES
]		ENUMsnmp加密协议
user <user-name>-STRING添加snmp用户
auth-protocol <auth-protocol-type>枚举值:[
md5: MD5规则
sha: SHA
]		ENUMsnmp认证协议
auth <auth-passwd-value>length:(8-95)STRING认证密码
enc <enc-passwd-value>length:(8-95)STRING加密密码
