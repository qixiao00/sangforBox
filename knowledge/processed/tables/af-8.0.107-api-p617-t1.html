参数类型是否必选描述
objobject是接口信息
obj.namestring是接口名称
obj.descriptionstring否接口描述
最小长度:0
最大长度:95
obj.vsysstring[]否虚拟系统
obj.mtuint32否最大传输单元
最小值:68
最大值:1500
默认值:1500
obj.ifTypestring是表示接口类型
枚举值:[
PHYSICALIF:物理口
SUBIF:子接口
CHANNELIF:聚合口
VLANIF:vlan对应的3层接口
VPNTUN:vpn隧道口
LOOPBACK:回环口
GRETUN:GRE隧道口
SSLTUN:SSL隧道口
VSYSIF:虚拟系统的虚拟接口
TUNNELIF:隧道口
]
obj.macstring--接口的mac地址，接口类型为物理口和聚
合口时使用
