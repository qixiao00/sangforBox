data.ifTypestring表示接口类型
枚举值:[
PHYSICALIF:物理口
SUBIF:子接口
CHANNELIF:聚合口
VLANIF:vlan对应的3层接口
VPNTUN:vpn隧道口
LOOPBACK:回环口
GRETUN:GRE隧道口
SSLTUN:SSL隧道口
VSYSIF:虚拟系统的虚拟接口
TUNNELIF:隧道口
]
data.macstring接口的mac地址，接口类型为物理口和聚合口时使用
data.shutdownbool接口的启用或禁用，接口类型为物理口和聚合口时使用
data.ifModestring接口的工作模式，接口类型为物理口和聚合口时使用
枚举值:[
ROUTE:路由类型，接口作为3层接口，提供IP地址配
置，路由配置转发等功能
SWITCH:交换类型，接口作为2层接口，提供二层转发
、vlan配置等功能
VIRTUALLINE:虚拟线类型，接口作为虚拟线的一端
，透明传输报文
BYPASSMIRROR:旁路镜像类型，该模式进来的报文
，只处理不转发
]
data.ipv4object接口ipv4相关配置，三层模式时使用
data.ipv4.ipv4ModestringIPv4地址获取类型
枚举值:[
STATIC:静态配置
DHCP:dhcp方式获取
PPPOE:pppoe方式获取
]
data.ipv4.staticIpobject[]IPv4地址列表，三层模式IPv4为静态IP时使用
data.ipv4.staticIp.ipaddressobjectIPv4地址
格式:ip-range
data.ipv4.staticIp.ipaddress.startstringip范围的起始位置
格式:ip-address
data.ipv4.staticIp.ipaddress.endstringip范围的终止位置
格式:ip-address
data.ipv4.staticIp.ipaddress.bitsuint8ip掩码简写
data.ipv4.staticIp.isSyncbool是否不同步到备机的选项
data.ipv4.dhcpobjectdhcp4 client配置，三层模式IPv4为DHCP时使用
data.ipv4.dhcp.gatewaybool是否设置dhcp gateway
data.ipv4.dhcp.dnsbool设置dns
data.ipv4.dhcp.unicastbool是否设置dhcp单播
