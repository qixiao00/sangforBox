参数类型是否必选描述
_orderstring否指定排序方式（正序/倒序）
默认值:asc
枚举值:[
asc:按升序排列
desc:按降序排列
]
_searchstring否模糊搜索关键字
最大长度:95
_startint32否起始位置，从 0 开始
最小值:0
最大值:2000000
send status_string否发送状态
枚举值:[
SUCCESS:推送成功
FAILED:推送失败
CFGERR:配置解析失败（详细错误需查看
后台日志，可能包含敏感信息）
WAIT:未推送
DUMP:被合并
]
_pagesizeint32否the count of each page
最小值:1
最大值:200
默认值:100
_sortbystring否指定排序字段
最大长度:100
start time_string否起始时间
_lengthint32否获取最大长度，限制最大值，如果数据不够
可能返回小于 length
最小值:1
最大值:200
默认值:100
end time_string否终止时间
