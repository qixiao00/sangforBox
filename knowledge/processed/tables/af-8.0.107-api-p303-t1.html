参数类型是否必选描述
objobject是网络对象
obj.namestring是网络对象组名字
最小长度:1
最大长度:95
obj.businessTypestring是网络对象组类型
枚举值:[
IP:ip组类型
BUSINESS:业务组类型
USER:用户组类型
ADDRGROUP:地址组类型
DOMAINS:域名类型
MACGROUP:mac地址组类型
]
obj.descriptionstring否描述字段
最小长度:0
最大长度:95
obj.addressTypestring否地址类型
默认值:IPV4
枚举值:[
IPV4:IPv4类型
IPV6:IPv6类型
MAC:mac类型
]
obj.domainsstring[]--域名对象
obj.domainsDetectModestring--域名对象探测模式
枚举值:[
ACTIVE:主动探测
PASSIVE:被动学习
]
obj.macListstring[]按条件选
择		mac地址组列表
obj.ipRangesobject[]按条件选
择		ip表项组 --
请求时该参数和参数refIpGroup二选一
obj.ipRanges.startstring是ip范围的起始位置
格式:ip-address
obj.ipRanges.endstring否ip范围的终止位置
格式:ip-address
obj.ipRanges.bitsuint8否ip掩码简写
