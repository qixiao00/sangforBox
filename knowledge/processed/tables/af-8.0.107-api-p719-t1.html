HIGH:高优先级

MEDIUM:中优先级
]

最小值:3
最大值:1800
默认值:200

min
最小值:4
最大值:1800
默认值:600

最小值:0
最大值:9000
默认值:100

ALL:周期性发送RA

DISABLE:不主动发送，也不应答
]

s），为0则使用RA中的
