参数类型是否必选描述
optionalItfbool否是否去除被聚合口选择的物理口
selectChannelbool否否为聚合口可选择的物理口
getChannelstring否获取该接口所属于的聚合口的配置
_startint32否起始位置，从 0 开始
最小值:0
最大值:2000000
zoneItfbool否是否为区域可选择的接口
_lengthint32否获取最大长度，限制最大值，如果数据不够
可能返回小于 length
最小值:1
最大值:200
默认值:100
routeItfbool否是否为三层接口
_sortbystring否指定排序字段
最大长度:100
haItfbool否获取可选择的HA接口
_orderstring否指定排序方式（正序/倒序）
默认值:asc
枚举值:[
asc:按升序排列
desc:按降序排列
]
VirtualHaItfbool否获取虚拟IP可使用的接口
_selectstring否选择字段，字段用逗号分隔
最大长度:1000
haMonitorItfbool否获取监视端口vlan和接口
ifTypestring否过滤参数：接口类型
枚举值:[
PHYSICALIF:物理口
SUBIF:子接口
CHANNELIF:汇聚口
VLANIF:vlan对应的3层接口
LOOPBACK:本地环回口
GRETUN:GRE隧道
VPNTUN:vpn隧道口
VSYSIF:虚拟接口
TUNNELIF:隧道口
]
