netobjs.addressTypestring否地址类型
默认值:IPV4
枚举值:[
IPV4:IPv4类型
IPV6:IPv6类型
MAC:mac类型
]
netobjs.domainsstring[]--域名对象
netobjs.domainsDetectModestring--域名对象探测模式
枚举值:[
ACTIVE:主动探测
PASSIVE:被动学习
]
netobjs.macListstring[]按条件选
择		mac地址组列表
netobjs.ipRangesobject[]按条件选
择		ip表项组 --
请求时该参数和参数refIpGroup二选一
netobjs.ipRanges.startstring是ip范围的起始位置
格式:ip-address
netobjs.ipRanges.endstring否ip范围的终止位置
格式:ip-address
netobjs.ipRanges.bitsuint8否ip掩码简写
netobjs.importantstring否标识核心业务/普通业务或者标识普通用户/
核心用户
默认值:COMMON
枚举值:[
COMMON:普通用户或普通业务
CORE:核心用户或核心业务
]
netobjs.refIpGroupstring[]按条件选
择		地址组引用的IP组对象列表 --
请求时该参数和参数ipRanges二选一
netobjs.dataStatusstring否标识敏感数据识别方式是自动识别或者存在
或者不存在
枚举值:[
AUTO:系统自动识别
EXIST:存在
NOT-EXIST:不存在
]
