参数类型是否必选描述
ipstring否要过滤的ip地址，若不选该字段，默认全部
格式:ip-address
sessionTypestring否并发会话数量或新建会话数量(默认NEW)
默认值:NEW
枚举值:[
CONCURRENT:并发会话数量
NEW:每秒新建会话数量
]
dateFilterstring否指定获取某天日期(yyyy-mm-dd)的数量
趋势
vsysstring否过滤的虚拟系统名称
最小长度:1
最大长度:15
timeFilterstring否最近多长时间段内的总会话数量趋势
枚举值:[
REAL-TIME:最近的总会话数量趋势
24HOUR:最近24小时的总会话数量趋势
7DAY:最近7天的总会话数量趋势
]
