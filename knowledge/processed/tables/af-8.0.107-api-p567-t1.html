PERIODICAL:循环时间计划
]

data.singleScheduleobject单次时间计划规则，scheduleType为SINGLE时必选
data.singleSchedule.startDateTimestring开始日期时间，示例：2020-11-11
data.singleSchedule.endDateTimestring结束日期时间，示例：2020-11-12
data.periodicalScheduleobject循环时间计划规则，scheduleType为PERIODICAL
时必选

data.periodicalSchedule.singleDetail.startDateTimestring开始日期时间，示例：2020-11-11
data.periodicalSchedule.singleDetail.endDateTimestring结束日期时间，示例：2020-11-12
data.periodicalSchedule.periodicalDetailobject[]循环时间计划周期规则
data.periodicalSchedule.periodicalDetail.weekstring[]循环周期
data.periodicalSchedule.periodicalDetail.startTimestring开始时间，示例：08:00:00
