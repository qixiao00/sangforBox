obj.userNamestring是ftp服务器用户名
最小长度:1
最大长度:95
obj.passwordstring是ftp服务器密码
最小长度:1
最大长度:95

择		本地文件名称(ftp上传才起作用)
最小长度:1
最大长度:255
obj.remoteFilestring是远程文件名称
最小长度:1
最大长度:255
