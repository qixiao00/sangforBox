netobj.namestring是网络对象组名字
最小长度:1
最大长度:95
netobj.businessTypestring是网络对象组类型
枚举值:[
IP:ip组类型
BUSINESS:业务组类型
USER:用户组类型
ADDRGROUP:地址组类型
DOMAINS:域名类型
MACGROUP:mac地址组类型
]
netobj.descriptionstring否描述字段
最小长度:0
最大长度:95
netobj.addressTypestring否地址类型
默认值:IPV4
枚举值:[
IPV4:IPv4类型
IPV6:IPv6类型
MAC:mac类型
]
netobj.domainsstring[]--域名对象
netobj.domainsDetectModestring--域名对象探测模式
枚举值:[
ACTIVE:主动探测
PASSIVE:被动学习
]
netobj.macListstring[]按条件选
择		mac地址组列表
netobj.ipRangesobject[]按条件选
择		ip表项组 --
请求时该参数和参数refIpGroup二选一
netobj.ipRanges.startstring是ip范围的起始位置
格式:ip-address
netobj.ipRanges.endstring否ip范围的终止位置
格式:ip-address
netobj.ipRanges.bitsuint8否ip掩码简写
netobj.importantstring否标识核心业务/普通业务或者标识普通用户/
核心用户
默认值:COMMON
枚举值:[
COMMON:普通用户或普通业务
CORE:核心用户或核心业务
]
netobj.refIpGroupstring[]按条件选
择		地址组引用的IP组对象列表 --
请求时该参数和参数ipRanges二选一
