参数类型描述
codeint错误码

dataobject分页数据
data.totalItemsint32总共多少项目

data.pageSizeint32每页多大
data.itemsOffsetint32当前条目偏移，从 0 开始
data.itemLengthint32数据列表长度
data.privateOffsetuint64内部偏移
data.itemsobject[]有效数据列表
data.items.uuidstring本条消息的ID
data.items.eventstring告警项目

data.items.atemplatestring指定服务商对应的信息模板ID，使用facilitator方式时

smsTo/emailTo/emailCc/emailBcc

data.items.address.emailTostring[]邮件目标地址
data.items.address.emailCcstring[]邮件抄送目标地址
data.items.address.emailBccstring[]邮件密送目标地址
data.items.alarmLevelstring告警等级
枚举值:[
urgent:紧急。严重影响业务
normal:正常。提示性，不影响业务
]
data.items.paramobject[]指定消息的 body,

subject/content

最小长度:0
最大长度:1024
