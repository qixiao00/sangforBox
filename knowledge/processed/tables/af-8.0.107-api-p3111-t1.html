obj.ether.typestring--按照帧类型过滤
枚举值:[
NONE:重置
IP:ip协议
IPv6:IPv6协议
ARP:ARP协议
PPPOED:PPPOED协议
PPPOES:PPPOES协议
EAPOL:EAPOL协议
WAI/WAPI:WAI/WAPI协议
]
obj.arpobject--arp过滤
obj.arp.senderIpstring--发送方ip地址过滤
obj.arp.senderMacstring--发送方Mac地址过滤
obj.arp.targetIpstring--目标方ip地址过滤
obj.arp.opstring--arp操作过滤
枚举值:[
NONE:重置
REPLY:响应过滤
REQUEST:请求过滤
]
obj.pppobject--ppp过滤
obj.ppp.protocolstring--协议过滤
枚举值:[
NONE:重置
IP:ip协议
IPv6:IPv6协议
LCP:LCP协议
PAP:PAP协议
CHAP:CHAP协议
]
obj.ipobject--ip过滤
obj.ip.hoststring--主机过滤ip
格式:ip-address
obj.ip.dsthoststring--目的主机过滤ip
格式:ip-address
obj.ip.srchoststring--源主机过滤ip
格式:ip-address
obj.ip.protocoluint8--协议过滤
最小值:0
最大值:255
obj.portobject--端口过滤
obj.port.portuint16--按照端口过滤
obj.port.dstportuint16--按照目的端口过滤
obj.port.srcportuint16--按照源端口过滤
obj.packetCountuint16--匹配报文的个数
最小值:0
最大值:2048
