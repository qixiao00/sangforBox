参数类型是否必选描述
connectStatusstring否过滤连接状态(默认为ALL)
默认值:ALL
枚举值:[
ALL:所有连接状态
ESTABLISH:已建立连接
CLOSE:已关闭连接
HANDSHAKE:半连接状态
]
vsysstring否过滤的虚拟系统名称
最小长度:1
最大长度:15
start
_		int32否起始位置，从 0 开始
最小值:0
最大值:2000000
srcIPstring否源IP
格式:ip-address
length
_		int32否获取最大长度，限制最大值，如果数据不够
可能返回小于 length
最小值:1
最大值:200
默认值:100
protocolstring否过滤协议(默认为ALL)
默认值:ALL
枚举值:[
ALL:所有协议
TCP:TCP协议
UDP:UDP协议
ICMP:ICMP协议
OTHER:其他协议
]
dstIPstring否目的IP（不选默认为全部）
格式:ip-address
