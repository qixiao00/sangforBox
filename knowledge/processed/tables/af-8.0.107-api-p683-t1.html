枚举值:[
ROUTE:路由类型，接口作为3层接口，提供IP地址配
置，路由配置转发等功能
SWITCH:交换类型，接口作为2层接口，提供二层转发
、vlan配置等功能
VIRTUALLINE:虚拟线类型，接口作为虚拟线的一端

BYPASSMIRROR:旁路镜像类型，该模式进来的报文
