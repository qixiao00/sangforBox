obj.snat.dstNetobj.zonestring[]按条件选
择		目的区域，当dstNetobjType类型为ZON
E时选择
obj.snat.dstIpGroupsstring[]是需要匹配的目的IP组
obj.snat.natServicestring[]是引用的服务组
obj.snat.transferobject是源地址转换相关数据
obj.snat.transfer.transferTypestring是源转换类型
默认值:OUTIF IP
_
枚举值:[
OUTIF IP:出接口ip
_
IP RANGE:ip范围
_
IP:单个ip
IPGROUP:ip组
NO TRANS:不转换
_
]
obj.snat.transfer.stickystring是转换模式开关
默认值:OFF
枚举值:[
OFF:关闭sticky功能
STRICT:开启sticky功能严格模式
LOOSE:开启sticky功能宽松模式
]
obj.snat.transfer.ipRangeobject按条件选
择		源转换IP范围参数，当transferType转换
类型为IP RANGE时选择
_
格式:ip-range
obj.snat.transfer.ipRange.startstring是IP范围起始地址
格式:ip-address
obj.snat.transfer.ipRange.endstring是IP范围结束地址
格式:ip-address
obj.snat.transfer.ipRange.tranferModestring否IP范围转换模式
默认值:DYNAMIC
枚举值:[
STATIC:静态转换
DYNAMIC:动态转换
]
obj.snat.transfer.specifyIpstring按条件选
择		转换的单个IP
obj.snat.transfer.ipGroupsstring[]按条件选
择		转换的IP组
obj.snat.transfer.transPortobject按条件选
择		源转换端口配置参数
obj.snat.transfer.transPort.portModestring是端口分配类型
默认值:RANDOM
枚举值:[
RANDOM:自由分配
STATIC BLOCK:静态端口段
_
]
obj.snat.transfer.transPort.portRangeobject是端口范围
格式:int-range
