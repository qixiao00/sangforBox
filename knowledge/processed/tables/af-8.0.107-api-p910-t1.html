_startint32否起始位置，从 0 开始
最小值:0
最大值:2000000
distanceuint8否路由管理距离，默认为1
最小值:1
最大值:255
_lengthint32否获取最大长度，限制最大值，如果数据不够
可能返回小于 length
最小值:1
最大值:200
默认值:100
ifnamestring否出接口名称，自动选择接口识别到的接口不
支持该参数过滤
最小长度:1
最大长度:48
_sortbystring否指定排序字段
最大长度:100
metricuint32否静态路由度量值
最小值:256
最大值:1023
_orderstring否指定排序方式（正序/倒序）
默认值:asc
枚举值:[
asc:按升序排列
desc:按降序排列
]
gatewaystring否下一跳IPv6地址
格式:ip6-address
