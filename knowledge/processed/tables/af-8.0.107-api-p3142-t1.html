上下文标题路径：8 运营中心 / 8.2 黑白名单 / 8.2.1 全量获取符合过滤条件的黑白IP

参数类型是否必选描述
_startint32否起始位置，从 0 开始
最小值:0
最大值:2000000
_searchstring否模糊搜索关键字
最大长度:95
urlstring否IP,IP网段或者域名,或者URL
最小长度:1
最大长度:4096
_selectstring否选择字段，字段用逗号分隔
最大长度:1000
typestring否黑名单 BLACK， 白名单 WHITE
枚举值:[
BLACK:黑名单
WHITE:白名单
]
descriptionstring否描述信息
最小长度:0
最大长度:95
_orderstring否指定排序方式（正序/倒序）
默认值:asc
枚举值:[
asc:按升序排列
desc:按降序排列
]
_sortbystring否指定排序字段
最大长度:100
_lengthint32否获取最大长度，限制最大值，如果数据不够
可能返回小于 length
最小值:1
最大值:200
默认值:100
