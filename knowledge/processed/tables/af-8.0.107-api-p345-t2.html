上下文标题路径：4 对象 / 4.2 链路探测 / 4.2.8 增量更新指定链路探测信息

参数类型是否必选描述
objobject是链路探测配置
obj.descriptionstring--策略的描述
最小长度:0
最大长度:95
obj.namestring--链路探测名称
最小长度:1
最大长度:95
obj.detectTypestring--协议类型
枚举值:[
IPV4:IPv4类型
IPV6:IPv6类型
]
obj.detectMethodstring--配置检测方式
默认值:ALL
枚举值:[
ALL:同时满足
ANY:任一满足
]
obj.hasrefbool--标识是否被引用
obj.pingobject--PING探测策略
obj.ping.enablebool--ping探测开关
obj.ping.address1string--目标地址1
格式:ip-address
obj.ping.address2string--目标地址2
格式:ip-address
obj.ping.interfacestring--探测出接口
最大长度:64
obj.ping.intervaluint32--检测间隔
最小值:2
最大值:255
默认值:2
