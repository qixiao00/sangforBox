_orderstring否指定排序方式（正序/倒序）
默认值:asc
枚举值:[
asc:按升序排列
desc:按降序排列
]
_startint32否起始位置，从 0 开始
最小值:0
最大值:2000000
_sortbystring否指定排序字段
最大长度:100
_lengthint32否获取最大长度，限制最大值，如果数据不够
可能返回小于 length
最小值:1
最大值:200
默认值:100
_searchstring否模糊搜索关键字
最大长度:95
deviceTypestring否设备类型
默认值:VROUTER
枚举值:[
VSWITCH:vswitch设备
VROUTER:vrouter设备
DVSWITCH:dvswitch设备
]
