参数类型是否必选描述
_deststring否目标位置关键字对应的值
最大长度:100
_arrayopstring否对象属性是数组的操作控制
枚举值:[
add:添加对应的数组元素
remove:删除对应的数组元素
]
_keystring否目标位置关键字
枚举值:[
position:指定目标位置关键字为 position
name:指定目标位置关键字为 name
]
_wherestring否指定位置，用于移动/插入
枚举值:[
top:顶部
bottom:底部
before:在目标位置之前
after:在目标位置之后
]
