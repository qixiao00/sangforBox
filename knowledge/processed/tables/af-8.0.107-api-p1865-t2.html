参数类型是否必选描述
objobject是NAT策略过滤请求负载
obj. start_int32--起始位置，从 0 开始
最小值:0
最大值:2000000
obj. length_int32--获取最大长度，限制最大值，如果数据不够
可能返回小于 length
最小值:1
最大值:200
默认值:100
obj.transTypestring--用于指定转换类型,
可选SNAT,DNAT,BNAT
枚举值:[
SNAT:转换类型为源地址转换
DNAT:转换类型为目的地址转换
BNAT:转换类型为双向地址转换
]
obj. search_string--模糊搜索关键字
最小长度:1
最大长度:95
obj.filterobject--NAT策略过滤条件
obj.filter.nameobject--过滤字段名称
obj.filter.name.comparestring--nat.policys.param: filter type
默认值:eq
枚举值:[
eq:包含过滤值
ne:不包含过滤值
]
obj.filter.name.parasstring[]--过滤值的集合
obj.filter.scheduleobject--过滤字段名称
