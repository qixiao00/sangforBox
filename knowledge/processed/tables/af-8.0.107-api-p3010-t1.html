packetPassuint8否日志类型

最小值:0
最大值:2000000
_selectstring否选择字段，字段用逗号分隔
最大长度:1000
_lengthint32否获取最大长度，限制最大值，如果数据不够
可能返回小于 length
最小值:1
最大值:200
默认值:100
dstPortint32否目的端口号
最小值:0
最大值:65535
tcpbool否是否查询TCP
udpbool否是否查询UDP
icmpbool否是否查询ICMP
icmpv6bool否是否查询ICMPV6
srcPortint32否源端口号
最小值:0
最大值:65535
srcIpstring否源IP地址
格式:ip-address
