obj.positionint32否表示位置状态
obj.natTypestring是nat6策略类型
枚举值:[
SNAT:转换类型为源地址转换
DNAT:转换类型为目的地址转换
BNAT:转换类型为源目的地址转换
]
obj.natModestring--ipv6-nat模式,可选项有NAT66|NPTV6
默认值:NAT66
枚举值:[
NAT66:转换类型为NAT66
NPTV6:转换类型为NPTV6
]
obj.descriptionstring否描述
最小长度:0
最大长度:95
obj.schedulestring--生效时间
默认值:00000000000000000000000c0
obj.snatobject按条件选
择		源地址转换信息
obj.snat.srcZonesstring[]是源区域信息
obj.snat.srcIpstring是源IPv6
格式:ip6-address
obj.snat.prefixuint8是源IP的前缀
最小值:4
最大值:128
obj.snat.srcIpGroupsstring[]--源IP信息
obj.snat.dstNetobjTypestring是SNAT6:需要匹配的目的类型
默认值:ZONE
枚举值:[
ZONE:区域
INTERFACE:接口
]
obj.snat.dstZonesstring[]是目的区域
obj.snat.dstInterfacestring--目的接口
obj.snat.dstIpobjobject--目的ip
obj.snat.dstIpobj.dstIpGroupsstring[]--目的ip组
obj.snat.dstIpobj.dstIpstring--源IP信息
格式:ip6-address
obj.snat.dstIpobj.prefixuint8--前缀
最小值:4
最大值:128
obj.snat.natServicestring[]--引用的服务组
obj.snat.transferobject是转换信息
