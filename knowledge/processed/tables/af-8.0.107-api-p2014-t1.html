obj.snat.transfer.srcIpTransstring是源IPv6转换
格式:ip6-address
obj.snat.transfer.prefixTransuint8是源IP的前缀
最小值:4
最大值:128
obj.snat.transfer.forceTransferobject--转换信息
obj.snat.transfer.forceTransfer.transferTypestring--转换类型 enum
默认值:OUTIF IP
_
枚举值:[
OUTIF IP:OUTIF IP
_ _
IP RANGE:IP段
_
IP:ip
IPGROUP:IP组
NO TRANS:不转换
_
]
obj.snat.transfer.forceTransfer.stickystring是转换模式开关
默认值:OFF
枚举值:[
OFF:关闭sticky功能
STRICT:开启sticky功能严格模式
LOOSE:开启sticky功能宽松模式
]
obj.snat.transfer.forceTransfer.ipRangeobject--ipv6范围
格式:ip-range
obj.snat.transfer.forceTransfer.ipRange.startstring--ip范围下界
格式:ip6-address
obj.snat.transfer.forceTransfer.ipRange.endstring--ip范围上界
格式:ip6-address
obj.snat.transfer.forceTransfer.specifyIpstring--单个ipv6
格式:ip6-address
obj.snat.transfer.forceTransfer.ipGroupsstring[]--ip组
obj.dnatobject按条件选
择		目的地址转换信息,二选一
obj.dnat.srcZonesstring[]是源区域
obj.dnat.srcIpobjobject--源地址信息
obj.dnat.srcIpobj.srcIpGroupsstring[]--源IP信息
obj.dnat.dstIpGroupsstring[]--目的IP信息
obj.dnat.natServicestring[]--引用的服务组
obj.dnat.dnatIgnoreAclbool--是否忽略访问控制
默认值:true
obj.dnat.bypassAclLogbool否忽略访问控制匹配上策略上报会话日志
obj.dnat.transferobject是转换信息
obj.dnat.transfer.dstPortTransobject[]--转换端口,0 表示不转换端口
