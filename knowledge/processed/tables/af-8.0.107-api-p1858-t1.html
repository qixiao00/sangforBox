参数类型是否必选描述
_searchstring否模糊搜索关键字
最大长度:95
_startint32否起始位置，从 0 开始
最小值:0
最大值:2000000
movesearchstring否移动搜索参数项
最小长度:1
最大长度:95
_lengthint32否获取最大长度，限制最大值，如果数据不够
可能返回小于 length
最小值:1
最大值:200
默认值:100
positionint32否移动搜索位置参数项
_selectstring否选择字段，字段用逗号分隔
最大长度:1000
__nameprefixstring否NAT名字前缀过滤
最小长度:1
最大长度:95
transTypestring否用于指定转换类型,
可选SNAT,DNAT,BNAT
枚举值:[
SNAT:转换类型为源地址转换
DNAT:转换类型为目的地址转换
BNAT:转换类型为双向地址转换
]
