obj.v4ToV6.natServicestring[]是引用的服务组
obj.v4ToV6.transferobject是转换信息
obj.v4ToV6.transfer.srcTransferobject是源地址转换信息
obj.v4ToV6.transfer.srcTransfer.srcTransferTypestring是源地址转换类型
默认值:OUTIF IP
_
枚举值:[
IP:单个IP转换
IP RANGE:IP范围转换
_
OUTIF IP:转换为出接口
_
]
obj.v4ToV6.transfer.srcTransfer.ipRangeobject按条件选
择		IP范围,不支持bits以及mask
格式:ip-range
obj.v4ToV6.transfer.srcTransfer.ipRange.startstring是ip范围的起始位置
格式:ip-address
obj.v4ToV6.transfer.srcTransfer.ipRange.endstring否ip范围的终止位置
格式:ip-address
obj.v4ToV6.transfer.srcTransfer.ipRange.bitsuint8否ip掩码简写
obj.v4ToV6.transfer.srcTransfer.ipv6string按条件选
择		IPv6地址
格式:ip6-address
obj.v4ToV6.transfer.dstTransferobject是目的地址转换信息
obj.v4ToV6.transfer.dstTransfer.ipv6Segmentstring是IPv6网段,掩码格式
obj.v4ToV6.transfer.dstTransfer.portTransTypestring是端口转换类型
默认值:NO TRANS
_
枚举值:[
PORT:端口转换
NO TRANS:不转换
_
]
obj.v4ToV6.transfer.dstTransfer.portTransobject[]否端口号,单个端口只需配置start
obj.v4ToV6.transfer.dstTransfer.portTrans.startint32是from nat64type:port range start
最小值:1
最大值:65535
obj.v4ToV6.transfer.dstTransfer.portTrans.endint32否from nat64type:port range end
最小值:1
最大值:65535
obj.v6ToV4object按条件选
择		IPv6转换为IPv4信息,二选一
obj.v6ToV4.srcZonesstring[]是源区域
obj.v6ToV4.srcIpGroupsstring[]是源ip组
