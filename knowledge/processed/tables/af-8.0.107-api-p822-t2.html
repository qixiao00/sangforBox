参数类型描述
codeint错误码
messagestring错误信息
dataobject分页数据
data.totalItemsint32总共多少项目
data.totalPagesint32总共多少页
data.pageNumberint32当前页码，从 1 开始
data.pageSizeint32每页多大
data.itemsOffsetint32当前条目偏移，从 0 开始
data.itemLengthint32数据列表长度
data.privateOffsetuint64内部偏移
data.itemsobject[]有效数据列表
data.items.namestring接口名称
最大长度:48
data.items.macstring端口的mac地址
data.items.portIdstring端口id
data.items.enablebool是否起禁用rstp
data.items.priorityuint8端口优先级
data.items.uptimeuint32启动到现在时间
data.items.pathCostuint32端口开销
data.items.edgebool是否是边缘端口
data.items.p2pAdminstring指定端口是否是点对点链路
枚举值:[
FORCETRUE:强制指定为点对点链路
FORCEFALSE:强制指定为非点对点链路
AUTO:系统自动检测是否为点对点链路
UNKNOW:未知，一般不会出现这种情况
]
data.items.p2pOperbool真实链路状态
